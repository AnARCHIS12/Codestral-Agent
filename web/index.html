📥 Installation

📦 Méthode 1 : Extension VS Code

  1. Ouvrez VS Code
  2. Allez dans Extensions (Ctrl+Shift+X)
  3. Recherchez "Codestral AI"
  4. Cliquez sur Installer

Bientôt disponible sur le Marketplace

💻 Méthode 2 : Installation manuelle

# Cloner le dépôt
cd Libre_Ai_agents/codestral-vscode-extension

# Installer les dépendances
npm install

# Compiler
npm run compile

# Lancer en mode debug (F5)
code .

📁 Méthode 3 : Depuis un fichier .vsix

# Installer vsce

💡 Utilisation

🔑 Configurer la clé API

1. Ouvrez la palette de commandes (Ctrl+Shift+P)

2. Tapez Codestral: Set API Key

3. Entrez votre clé (ex: 2CY5...)

2CY5**************************** Copier

⌨️ Compléter du code

1. Placez votre curseur dans le code

2. Appuyez sur Ctrl+Alt+C ou exécutez Codestral: Complete Code

3. Le code généré apparaît instantanément

// Avant
def calculate_factorial(n):
    if n <= 1:
        return 1

// Après
def calculate_factorial(n):
    if n <= 1:
        return 1
    else:
        return n * calculate_factorial(n-1)

💬 Utiliser le chat

1. Appuyez sur Ctrl+Alt+Shift+C ou exécutez Codestral: Chat

2. Posez votre question

3. La réponse s'ouvre dans un nouvel onglet
